# NekoAI v0.4.62 — Abrir projeto existente

- `Abrir outro projeto` no seletor de projetos agora abre o seletor de pastas do Windows.
- A pasta escolhida é aberta diretamente como workspace existente.
- Não abre mais o modal `Criar novo projeto`.
- O projeto aberto é adicionado/atualizado em `Projetos recentes`.
- `Novo Projeto` continua usando o fluxo de criação com nome + pasta pai.
- Se o usuário cancelar o seletor, nada é alterado.
