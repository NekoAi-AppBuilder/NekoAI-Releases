# NekoAI Desktop — Releases oficiais

Este repositório público é dedicado exclusivamente à distribuição do **NekoAI Desktop para Windows**.

## Downloads e atualizações

Acesse **Releases** para baixar o instalador mais recente. O aplicativo verifica atualizações por meio das releases oficiais deste repositório.

- Site oficial: https://nekoai.lovinfinity.com.br/
- Releases: https://github.com/NekoAi-AppBuilder/NekoAI-Releases/releases

## Segurança

O código-fonte, as integrações privadas, os serviços de backend e as credenciais não são publicados neste repositório.

Para suporte ou informações sobre o NekoAI, utilize os canais oficiais do aplicativo.
