# NekoAI

## AI App Builder para criar, editar e publicar projetos com Inteligência Artificial

O **NekoAI** é uma plataforma desktop desenvolvida para facilitar a criação, edição, evolução e publicação de projetos utilizando Inteligência Artificial.

Em vez de depender de uma única ferramenta ou de um único modelo de IA, o NekoAI reúne diferentes recursos em um único ambiente de desenvolvimento, permitindo trabalhar diretamente com os arquivos do projeto, visualizar as alterações em tempo real e utilizar diferentes modelos de IA para construir e modificar aplicações.

---

## O que é o NekoAI?

O NekoAI foi criado para quem quer utilizar Inteligência Artificial como parte real do processo de desenvolvimento.

Com ele, você pode:

- Criar projetos do zero utilizando IA;
- Editar projetos existentes;
- Trabalhar diretamente com os arquivos do projeto;
- Utilizar diferentes modelos de Inteligência Artificial;
- Visualizar o projeto em um Preview integrado;
- Navegar entre as páginas reais da aplicação;
- Integrar projetos com GitHub;
- Publicar projetos utilizando Vercel;
- Integrar bancos de dados através do Supabase;
- Trabalhar com projetos criados em outras plataformas;
- Utilizar recursos de análise de imagens quando disponíveis;
- Acompanhar tarefas executadas pela IA;
- Interagir com a IA durante o desenvolvimento;
- Monitorar logs e informações do projeto.

O objetivo é transformar o desenvolvimento assistido por IA em um processo mais completo, visual e controlável.

---

# Principais recursos

## 🤖 Desenvolvimento com múltiplas IAs

O NekoAI permite trabalhar com diferentes modelos de Inteligência Artificial dentro do mesmo ambiente.

Isso possibilita escolher o modelo mais adequado para cada tarefa, seja para:

- Criar funcionalidades;
- Corrigir problemas;
- Refatorar código;
- Analisar projetos;
- Criar páginas;
- Modificar interfaces;
- Trabalhar com arquivos;
- Resolver erros.

A disponibilidade dos modelos depende dos provedores e das configurações disponíveis no momento.

---

## 🏗️ Criação de projetos

Crie um novo projeto e utilize a Inteligência Artificial para construir sua aplicação.

O NekoAI trabalha diretamente com a estrutura real do projeto, permitindo que a IA crie e altere arquivos enquanto você acompanha o resultado.

---

## ✏️ Edição de projetos existentes

O NekoAI também pode ser utilizado para continuar o desenvolvimento de projetos que já existem.

Você pode abrir um projeto local e solicitar alterações como:

- Criar novas páginas;
- Alterar componentes;
- Corrigir erros;
- Modificar layouts;
- Adicionar funcionalidades;
- Refatorar código;
- Melhorar responsividade;
- Ajustar integrações.

---

## 👁️ Preview integrado

Visualize o projeto diretamente dentro do NekoAI.

O Preview permite acompanhar as alterações realizadas pela IA sem precisar sair do aplicativo.

Recursos incluem:

- Preview integrado;
- Atualização do projeto;
- Navegação entre páginas;
- Seleção de páginas/rotas;
- Abertura da rota atual em nova janela;
- Preservação da rota durante atualizações;
- Integração com o servidor de desenvolvimento.

---

## 📄 Page Selector

Projetos que possuem múltiplas páginas podem utilizar o seletor de páginas do NekoAI.

O sistema identifica as rotas reais encontradas no projeto e permite navegar entre elas diretamente pelo Preview.

Isso evita depender de uma lista fixa de páginas e permite trabalhar com a estrutura real da aplicação.

---

## 🧠 Task Runner

O NekoAI possui um sistema de execução de tarefas para acompanhar o trabalho realizado pela Inteligência Artificial.

O Task Runner permite controlar o ciclo de execução da tarefa, incluindo:

- Execução;
- Análise;
- Alterações nos arquivos;
- Validação;
- Perguntas ao usuário;
- Aprovações;
- Correções;
- Conclusão;
- Cancelamento.

O objetivo é evitar que a IA simplesmente execute comandos sem que o usuário tenha controle sobre o processo.

---

## 💬 Interação com a IA

Durante uma tarefa, a IA pode precisar de informações ou decisões do usuário.

O NekoAI permite interagir com essas solicitações diretamente dentro da aplicação.

Isso torna possível trabalhar de maneira mais colaborativa:

**Usuário → IA → decisão → execução → validação**

---

## 🖼️ Análise de imagens

Quando o modelo utilizado possui suporte visual, o NekoAI permite trabalhar com imagens durante o desenvolvimento.

Para modelos que não possuem suporte nativo a imagens, o sistema pode utilizar um mecanismo auxiliar de análise visual quando disponível.

Assim, imagens podem ser utilizadas como contexto para tarefas de desenvolvimento e análise.

---

## 🖥️ Console e diagnóstico

O NekoAI possui recursos para acompanhar informações geradas pelo Preview, incluindo mensagens de console e erros.

Isso facilita a identificação de problemas durante o desenvolvimento sem precisar abrir ferramentas externas.

# GitHub

O NekoAI possui integração com GitHub para trabalhar com projetos versionados.

É possível utilizar o GitHub para:

- Conectar projetos;
- Trabalhar com repositórios;
- Selecionar branches;
- Clonar projetos;
- Continuar o desenvolvimento de projetos existentes;
- Organizar o código utilizando versionamento.

A integração foi desenvolvida para permitir que o projeto continue sendo seu e permaneça acessível através do seu repositório.

---

# Vercel

O NekoAI possui integração com a Vercel para facilitar a publicação de aplicações.

Através da integração, é possível trabalhar com:

- Deploy;
- Projetos Vercel;
- Publicação de aplicações;
- Domínios personalizados;
- Acompanhamento da publicação.

Isso permite sair de um projeto desenvolvido localmente para uma aplicação publicada na internet com poucos passos.

---

# Supabase

O NekoAI também possui integração com Supabase.

O Supabase pode ser utilizado como infraestrutura para aplicações que precisam de recursos como:

- Banco de dados;
- Autenticação;
- Backend;
- APIs;
- Armazenamento.

A integração permite conectar projetos desenvolvidos no NekoAI aos recursos do Supabase.

---

# Projetos criados em outras plataformas

O NekoAI também pode ser utilizado para continuar trabalhando em projetos desenvolvidos originalmente em outras ferramentas de criação com IA.

Isso permite importar ou conectar um projeto existente e continuar sua evolução utilizando o ambiente do NekoAI.

---

# Preview de páginas

O NekoAI identifica as páginas e rotas reais existentes no projeto.

Com isso, você pode selecionar uma página diretamente no Preview, por exemplo:

- `/`
- `/sobre`
- `/contato`
- `/tutoriais`
- `/dashboard`

A lista é baseada na estrutura encontrada no projeto e não em páginas fictícias criadas pelo aplicativo.

# Licenciamento

O NekoAI utiliza um sistema de licenciamento para controlar o acesso ao aplicativo.

Cada licença possui uma chave exclusiva.

### Licenças

As licenças podem possuir diferentes modalidades e períodos de validade.

Também existem **licenças de teste**, destinadas a quem deseja experimentar o NekoAI antes de adquirir uma licença.

As chaves de teste possuem o formato:

`NEKO-TEST-XXXX-XXXX-XXXX`

Exemplo:

`NEKO-TEST-1234-5678-9012`

A validade de uma licença de teste é definida no momento de sua criação.

---

## Como adquirir uma licença

Para adquirir uma licença do NekoAI, acesse o site oficial do produto:

[NekoAI — Site oficial](https://nekoai.lovinfinity.com.br/)

Após a aquisição, a chave de licença é disponibilizada para ativação do aplicativo.

---

## Como ativar

1. Instale o NekoAI;
2. Abra o aplicativo;
3. Acesse a área de licença;
4. Informe sua chave;
5. Clique em **Ativar Licença**;
6. Aguarde a validação;
7. Comece a utilizar o NekoAI.

A ativação é vinculada ao sistema de licenciamento do NekoAI e respeita as regras de validade e dispositivos da licença.

# Atualizações

O NekoAI possui um sistema de atualização automática.

Quando uma nova versão é disponibilizada, o aplicativo pode identificar a atualização e apresentar a opção de baixar e instalar a nova versão diretamente pelo próprio NekoAI.

Isso permite manter o aplicativo atualizado sem precisar realizar todo o processo de instalação manualmente.

# Segurança

O NekoAI foi desenvolvido considerando a segurança dos projetos e das credenciais utilizadas durante o desenvolvimento.

Entre os cuidados adotados estão:

- Proteção das chaves de licença;
- Armazenamento seguro de informações sensíveis;
- Validação do diretório do projeto;
- Separação entre o diretório da aplicação e o diretório do usuário;
- Proteções durante operações de projeto;
- Controle de permissões durante tarefas da IA;
- Validação das operações de integração.

Credenciais e chaves privadas nunca devem ser compartilhadas publicamente.

# Filosofia do NekoAI

O NekoAI não pretende substituir o desenvolvedor.

A proposta é colocar a Inteligência Artificial ao lado do usuário como uma ferramenta de desenvolvimento.

Você define o que deseja construir.

A IA ajuda a executar.

O NekoAI fornece o ambiente para controlar, visualizar, testar e publicar o resultado.
