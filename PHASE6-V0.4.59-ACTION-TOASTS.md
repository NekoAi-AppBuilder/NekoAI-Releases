# NekoAI v0.4.59 — Action Toasts

## Objetivo
Adicionar feedback visual imediato para ações concluídas pelo usuário.

## Implementado
- Toast global, compacto e não bloqueante.
- Copiar resposta do chat: `Copiado`.
- Copiar mensagem do usuário: `Copiado`.
- Copiar código de autorização do GitHub: `Copiado`.
- Falha de clipboard: `Não foi possível copiar`.
- Undo de tarefa: `Tarefa desfeita`.
- Toast usa o mesmo visual escuro/roxo da NekoAI.
- Auto-dismiss em 1,8s.
- `aria-live=status` para feedback acessível.
